# LoJSync - Equipe de Tecnologia

Este projeto foi criado como uma demonstração de uma landing page interativa para a equipe fictícia **LoJSync**, desenvolvida utilizando **HTML**, **CSS** e **JavaScript**. ✨

A principal funcionalidade do projeto é permitir a navegação entre diferentes personagens da equipe, exibindo suas informações e alterando dinamicamente o conteúdo da página através de interações com JavaScript.

[<img src="./src/imagens/preview.gif" alt="Demonstração da navegação entre personagens">](https://diogostratega.github.io/projeto-equipe-tech/)

## Tecnologias utilizadas

* HTML
* CSS
* JavaScript

## Funcionalidades

### Navegação entre personagens

**1. Selecione um personagem**:

* Clique em um dos ícones disponíveis na lateral da página.

**2. Visualize as informações**:

* O personagem selecionado será destacado.
* As informações exibidas na tela serão atualizadas automaticamente.

### Responsividade

* O layout foi desenvolvido para se adaptar a diferentes tamanhos de tela.
* Imagens específicas são utilizadas para melhorar a experiência em dispositivos móveis.

## Objetivos do projeto

Este projeto foi desenvolvido com foco em prática e aprendizado de:

* Estruturação semântica com HTML.
* Estilização e responsividade com CSS.
* Manipulação do DOM com JavaScript.
* Organização de código e boas práticas de desenvolvimento front-end.
* Controle de versão utilizando Git e GitHub.
